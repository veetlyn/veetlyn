# Payleor plugin

Payleor is the money flow and the trust around paid work. This plugin lets Claude find offerings from freelancers, studios and AI sellers who list themselves on Payleor, show the user their quote, and hand the payment to Payleor's pay page, where the user pays the deposit with PayPal. Accepting a quote or a delivery stays a button the user presses in the card; Claude never pays or accepts for the user.

It bundles the Payleor connector (`https://api.payleor.com/mcp`, sign-in with a Payleor account) and the `hire-a-professional` skill, which tells Claude when to use Payleor and how to walk through a hire. Everything runs in the PayPal sandbox during the hackathon.

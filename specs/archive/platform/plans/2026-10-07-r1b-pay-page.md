# R1b: Pay Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A client opens a pay link, sees what they are paying, and pays with the PayPal button (JS SDK v6). The page shows the paid, processing and cancelled states. The client page links to the pay page. The R1a walkthrough's R1b gaps are fixed: owners and workspace admins can be assigned and quote, error responses carry no stack traces, PayPal orders list the payment's lines, and start and capture are rate-limited per payment.

**Architecture:** The server work is small: `isDev: false` on tRPC; effective services-team roles (S1's `effectiveServicesTeamRole`) in `project.members` and the assignment check; `items` on the PayPal order; a `request_limit` table with an atomic `hitRequestLimit`, used by `payStart` and `payCapture`; no pay path for balance payments until run 2. The web app gains `@paypal/paypal-js`, a pure `payPageState` model with tests, the `/pay/[token]` page and a `PayPalCheckout` component that loads the v6 SDK, checks eligibility, mounts a `<paypal-button>` and runs a one-time payment session whose order comes from `payStart` and whose approval calls `payCapture`.

**Tech Stack:** TypeScript, React 19 on vinext, TanStack Query 5, tRPC 11, Drizzle ORM 1.0 rc, Vitest 5, `@paypal/paypal-js` 11 (`sdk-v6` subpath), pnpm workspaces.

**Spec:** [`../2026-10-05-services-teams-design.md`](../2026-10-05-services-teams-design.md) §5.4 (pay page); [`../2026-10-07-sellers-minimal-flow-design.md`](../2026-10-07-sellers-minimal-flow-design.md) §11 (run 1) and §11.1 (backlog); PayPal facts in [`../2026-10-07-r1-paypal-facts.md`](../../../platform/2026-10-07-r1-paypal-facts.md) §1 and §5; R1a's "Carried forward" and "Sandbox walkthrough" in [`2026-10-07-r1a-server-payments.md`](2026-10-07-r1a-server-payments.md).

## Facts this plan relies on

From [`../2026-10-07-r1-paypal-facts.md`](../../../platform/2026-10-07-r1-paypal-facts.md) §5 and the `@paypal/paypal-js` source in `refs/paypal/paypal-js/packages/paypal-js` (npm `latest` is 11.2.1 on 2026-10-07):

1. `import { loadCoreSdkScript } from "@paypal/paypal-js/sdk-v6"`. `loadCoreSdkScript({ environment: "sandbox" | "production" })` resolves to the `paypal` namespace, or `null` on the server.
2. `paypal.createInstance({ clientId, merchantId, partnerAttributionId, components: ["paypal-payments"], pageType: "checkout" })`. Partners must pass the seller's `merchantId`. No client token is needed.
3. `instance.findEligibleMethods({ currencyCode })` returns an object with `isEligible("paypal")`.
4. `instance.createPayPalOneTimePaymentSession({ onApprove, onCancel, onError })`. `onApprove` receives `{ orderId }`.
5. `session.start({ presentationMode: "auto" }, createOrderPromise)`: pass the **promise** `Promise<{ orderId }>`, not a function, and call `start` inside the click handler so the popup is not blocked.
6. `<paypal-button>` is a custom element (`HTMLElementTagNameMap["paypal-button"]` has `type?: "pay" | ...`). Create it with `document.createElement` and listen for `click`.
7. Do not load the v5 SDK on the same page. There is no CSP in this app today, so no headers change.
8. Order items: each item needs `name` (1–127 characters), `quantity` (a string) and `unit_amount`; with items, `amount.breakdown.item_total` must equal the sum of the items, and `amount.value` must equal `item_total` when there is no tax or shipping.
9. tRPC 11 puts `stack` in error responses when `isDev` is true, and defaults `isDev` from `NODE_ENV`.

```ts
import { sql } from "drizzle-orm";

import type { DbExecutor } from "../executor";
import { requestLimit } from "../schema/limits";

// One atomic upsert: a hit either opens a new window or adds to the current one, so concurrent hits
// from different isolates cannot both slip under the limit.
export async function hitRequestLimit(
  db: DbExecutor,
  input: { key: string; windowMs: number; max: number; now?: number },
): Promise<boolean> {
  const now = input.now ?? Date.now();
  const expired = sql`${requestLimit.windowStart} <= ${now - input.windowMs}`;
  const [row] = await db
    .insert(requestLimit)
    .values({ key: input.key, windowStart: now, count: 1 })
    .onConflictDoUpdate({
      target: requestLimit.key,
      set: {
        windowStart: sql`case when ${expired} then ${now} else ${requestLimit.windowStart} end`,
        count: sql`case when ${expired} then 1 else ${requestLimit.count} + 1 end`,
      },
    })
    .returning({ count: requestLimit.count });
  if (!row) throw new Error("Upsert into request_limit returned no row");
  return row.count <= input.max;
}
```

If Drizzle renders the `set` column references ambiguously and Postgres errors, qualify them with `sql.raw('"request_limit"."window_start"')` and `sql.raw('"request_limit"."count"')`.

```ts
export type PaymentKind = "deposit" | "top_up" | "balance";
export type PaymentStatus = "pending" | "captured" | "failed" | "cancelled";
export type CaptureOutcome = "captured" | "pending" | "declined";

export type PayPageInput = {
  kind: PaymentKind;
  status: PaymentStatus;
  // A capture PayPal has not finished (payGet: pending with a capture id).
  processing: boolean;
  // The server has PayPal configured and the team has connected its account.
  paypalReady: boolean;
};

export type PayPageState =
  | { view: "pay" }
  | { view: "paid"; message: string }
  | { view: "processing"; message: string }
  | { view: "closed"; message: string };

export function payPageState(input: PayPageInput): PayPageState {
  if (input.status === "captured") return { view: "paid", message: "Paid. Thank you." };
  if (input.status === "cancelled") return { view: "closed", message: "This payment was cancelled." };
  if (input.processing) {
    return { view: "processing", message: "PayPal is still processing this payment. This page updates on its own." };
  }
  // startPayment refuses balances until run 2.
  if (input.kind === "balance") return { view: "closed", message: "The balance opens once you accept the delivery." };
  if (!input.paypalReady) {
    return { view: "closed", message: "This team cannot take PayPal payments yet. Ask them to connect PayPal." };
  }
  return { view: "pay" };
}

export function paymentKindLabel(kind: PaymentKind): string {
  switch (kind) {
    case "deposit":
      return "Deposit";
    case "top_up":
      return "Top-up";
    case "balance":
      return "Balance";
  }
}

// Null when the page's own state says enough (paid, or processing).
export function captureOutcomeProblem(outcome: CaptureOutcome): string | null {
  return outcome === "declined" ? "PayPal declined this payment. Try again or choose another way to pay." : null;
}

export function sdkEnvironment(environment: "sandbox" | "live"): "sandbox" | "production" {
  return environment === "live" ? "production" : "sandbox";
}
```

```tsx
"use client";

import { loadCoreSdkScript } from "@paypal/paypal-js/sdk-v6";
import { useEffect, useRef, useState } from "react";

import { captureOutcomeProblem, sdkEnvironment } from "@/lib/pay-page";
import { queryClient, trpc, trpcClient } from "@/utils/trpc";

export type PayPalSetup = {
  clientId: string;
  partnerAttributionId: string;
  environment: "sandbox" | "live";
  merchantId: string;
};

function messageOf(error: unknown): string {
  return error instanceof Error && error.message ? error.message : "Something went wrong. Try again.";
}

// Services spec §5.4 and R1 facts §5: the v6 SDK with the partner's client ID and the seller's merchant ID.
// The order comes from payStart (the server decides the amount); approval calls payCapture.
export default function PayPalCheckout({ token, currency, paypal }: { token: string; currency: string; paypal: PayPalSetup }) {
  const container = useRef<HTMLDivElement>(null);
  const [problem, setProblem] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const { clientId, partnerAttributionId, environment, merchantId } = paypal;

  useEffect(() => {
    let stopped = false;
    const refresh = () => queryClient.invalidateQueries({ queryKey: trpc.payment.payGet.queryKey({ token }) });

    async function mount() {
      const sdk = await loadCoreSdkScript({ environment: sdkEnvironment(environment) });
      if (!sdk || stopped) return;
      const instance = await sdk.createInstance({
        clientId,
        merchantId,
        partnerAttributionId,
        components: ["paypal-payments"],
        pageType: "checkout",
      });
      const methods = await instance.findEligibleMethods({ currencyCode: currency });
      if (stopped) return;
      if (!methods.isEligible("paypal")) {
        setProblem("PayPal is not available for this payment.");
        return;
      }
      const session = instance.createPayPalOneTimePaymentSession({
        onApprove: async ({ orderId }) => {
          setBusy(true);
          try {
            const { outcome } = await trpcClient.payment.payCapture.mutate({ token, orderId });
            setProblem(captureOutcomeProblem(outcome));
          } catch (error) {
            setProblem(messageOf(error));
          } finally {
            setBusy(false);
            await refresh();
          }
        },
        onCancel: () => setProblem(null),
        onError: () => setProblem("PayPal could not finish the payment. Try again."),
      });
      const button = document.createElement("paypal-button");
      button.type = "pay";
      button.addEventListener("click", () => {
        setProblem(null);
        // start() must run inside the click so the popup is allowed, and takes the order promise itself.
        const order = trpcClient.payment.payStart.mutate({ token });
        session.start({ presentationMode: "auto" }, order).catch((error: unknown) => {
          setProblem(messageOf(error));
          void refresh();
        });
      });
      container.current?.replaceChildren(button);
    }

    mount().catch(() => {
      if (!stopped) setProblem("PayPal could not load. Reload the page to try again.");
    });
    const mounted = container.current;
    return () => {
      stopped = true;
      mounted?.replaceChildren();
    };
  }, [token, currency, clientId, partnerAttributionId, environment, merchantId]);

  return (
    <div className="space-y-2">
      <div ref={container} aria-busy={busy} className={busy ? "pointer-events-none opacity-50" : undefined} />
      {busy ? <p className="text-sm text-muted-foreground">Confirming your payment…</p> : null}
      {problem ? (
        <p role="alert" className="text-sm text-destructive">
          {problem}
        </p>
      ) : null}
    </div>
  );
}
```

# C Plugin and Conversations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A client hires from Claude or ChatGPT end to end — search listed offerings, request, answer questions, accept and pay through widget buttons — while sellers quote, ask or decline with a reason, and every surface (plugin, web, client page) reads the same conversations from one core rule.

**Architecture:** One migration adds the conversations tables, the listing flags and the declined/expired statuses. Pure core functions (`conversationAccess`, `maskContactDetails`) decide who sees what and what shows pre-acceptance. New registry actions (`conversation.post/answer`, `request.decline/shortlist`, `member.departments`, `offering.search`) run through `perform`; existing use cases write `event` messages in their transactions. The web gains the Open requests board, staff tabs, the client page conversation UI, and the client HQ home; the client and pay pages move to `{team}.payleor.app`. The spike's MCP/OAuth/widget code is ported onto `perform` with A2 contacts as the client identity.

**Tech Stack:** TypeScript (pnpm, turbo), Drizzle on Postgres, Hono (api Worker), vinext (web Worker), Better Auth (`mcp`, `cimd`, `jwt` plugins — already in `packages/auth` on the spike branch), MCP SDK v2 + ext-apps, Vitest with a real test database.

```ts
import { index, pgTable, text, timestamp, uniqueIndex, uuid } from "drizzle-orm/pg-core";
import { project, team, user } from "./index";
import { clientContact } from "./contacts";

export const conversationMessage = pgTable(
  "conversation_message",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    projectId: uuid("project_id").notNull().references(() => project.id, { onDelete: "cascade" }),
    space: text("space", { enum: ["request", "project"] }).notNull(),
    authorKind: text("author_kind", { enum: ["client", "member", "system"] }).notNull(),
    authorUserId: text("author_user_id").references(() => user.id),
    authorContactId: uuid("author_contact_id").references(() => clientContact.id),
    kind: text("kind", { enum: ["text", "question", "answer", "event"] }).notNull(),
    body: text("body").notNull(),
    shownBody: text("shown_body").notNull(),
    replyToId: uuid("reply_to_id"),
    refType: text("ref_type"),
    refId: text("ref_id"),
    surface: text("surface", { enum: ["web", "mcp", "discord", "api", "email"] }).notNull(),
    discordMessageId: text("discord_message_id"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [index("conversation_message_project_idx").on(t.projectId, t.createdAt)],
);

export const memberDepartment = pgTable(
  "member_department",
  {
    teamId: text("team_id").notNull().references(() => team.id, { onDelete: "cascade" }),
    userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
    departmentId: uuid("department_id").notNull(),
  },
  (t) => [uniqueIndex("member_department_unique").on(t.teamId, t.userId, t.departmentId)],
);

export const requestShortlist = pgTable(
  "request_shortlist",
  {
    projectId: uuid("project_id").notNull().references(() => project.id, { onDelete: "cascade" }),
    userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  },
  (t) => [uniqueIndex("request_shortlist_unique").on(t.projectId, t.userId)],
);
```

3. Run the seed against the staging database: `DATABASE_URL=<staging> bun packages/db/scripts/demo-seed-conversations.ts --team walk-crew --department Design --freelancers <f1>,<f2> --unlisted-team <another team>`.
4. Build the staging zips: `pnpm plugin:zip --mcp-url https://api.staging.payleor.com/mcp`.
5. **AGT-09:** upload `payleor-plugin-staging.zip` in Claude and `payleor-plugin-chatgpt-staging.zip` in ChatGPT; connect, sign in as the client, check the consent page names `claude.ai` / `chatgpt.com`, Allow. Both list the tools.
6. **AGT-10:** "Find me someone to design a logo for my bakery under $400 in 5 days": only walk-crew's listed offerings; the other team's unlisted offering and the "Not in AI assistants" department never appear.
7. **AGT-11:** request it; the project appears on `dash.staging.payleor.com/walk-crew/projects` and on both freelancers' **Open requests**; the client email links to `walk-crew.staging.payleor.app/c/…`.
8. **AGT-31/32:** as freelancer 1, ask a question with an email, a phone number, a WhatsApp link and a Drive link; answer from the card ("Answer in the chat", approve the wording) and a second one on the client page. Check the masking on the client page, the card and the dash; as an admin, see "As written (admins only)".
9. **AGT-34:** both freelancers quote; the card shows two slides; accept one with its button; the other freelancer loses the request; the winner sees the history in the Project tab.
10. **AGT-12/13/15:** ask the AI to list its Payleor tools (no `accept_quote` or `accept_delivery`), to repeat any confirmation from the card (it cannot), then to accept for you (nothing happens); press **Accept quote**; press **Pay … with PayPal** (opens `walk-crew.staging.payleor.app/pay/…`), approve as the sandbox buyer, **Check payment**.
11. **AGT-14:** deliver on the dash; accept the delivery from the card; pay the balance.
12. **AGT-33:** a new request; decline it on the dash, first with an empty reason, then with one; the card and the client page show the reason.
13. **AGT-35:** sign in on the dash as the client; **Your projects as a client** lists the projects with links to each team's site.
14. **AGT-36:** open a client link on another team's subdomain (not found) and the old `staging.payleor.com/c/…` form (redirects to the team's site); the same for `/pay/…`.
15. Run the golden prompts in both clients and fill the table.
16. On `dash.staging.payleor.com/account`, as the client: **Connected AI apps** lists Claude and ChatGPT; **Disconnect** one, and its next tool call asks to connect again.

# Backlog

Open gaps found in testing, reviews and design, each with the run that owns it. Gaps for after the hackathon, or waiting on a feature that is not planned yet, are in [`backlog-later.md`](backlog-later.md); move one back here when a run takes it. When a run picks an item up, it names it in its plan; when the work merges, move the row to [`archive/backlog-done.md`](archive/backlog-done.md) with the commit. New findings from a walkthrough or review go into **Open** the same day.
